# Sample files

Small demo inputs and reference outputs used during development and in
the test suite. Everything in this directory is original work by the
`svg2fcm` authors — no third-party artwork is included — and is
distributed under the same [Mozilla Public License 2.0](../LICENSE) as
the rest of the project.

The Canvas-Workspace-exported `.fcm` files contain no third-party
artistic content; they encode trivial geometric primitives (lines,
rectangles, circles) drawn solely to exercise the file format. They are
included for **interoperability testing** — see
[`docs/FCM_FORMAT.md`](../docs/FCM_FORMAT.md) for the legal basis.

If you contribute a new sample, please add a row here and confirm it is
either your own work or under an MPL-2.0-compatible license.
